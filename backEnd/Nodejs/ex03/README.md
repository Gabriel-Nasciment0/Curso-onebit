# Anotacoes Rapidas CLI

Aplicacao Node.js para criar, listar, ler e excluir anotacoes de terminal.

## Como executar

1. Abra o terminal nesta pasta.
2. Execute `npm start`.
3. Escolha uma opcao do menu.

As anotacoes sao salvas como arquivos `.txt` na pasta `notes`, criada automaticamente ao iniciar a aplicacao.
